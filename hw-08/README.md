#ДЗ 8. Функции в Bash
**Задание:** изучение функций в Bash, их синтаксиса (без указания аргументов в скобках), локальных переменных (local) и кода возврата (return). Разбор отличий `return` от `exit`. Написание трёх скриптов: вывод текста в заданный поток (stdout, stderr, файл), вывод системной информации по ключевому слову, динамический вывод значения переменной через eval с циклом до EOF (Ctrl+D).
