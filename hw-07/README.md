# ДЗ 7. Создание демонов
Задание: освоить создание фоновых программ-демонов в Unix-подобных ОС, научиться писать Bash-скрипт с логированием в syslog и обработкой сигналов завершения (SIGTERM, SIGINT), а также настраивать запуск демона через конфигурационные файлы systemd как на стороне пользователя (~/.config/systemd/user/), так и на стороне системы (/etc/systemd/system/).
