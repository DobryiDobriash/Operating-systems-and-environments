# ДЗ 4. Администрирование

**Задание:** команды для работы с процессами и справкой: вывести дерево процессов, процессы не от своего пользователя, пять процессов с наибольшим потреблением памяти (`head`), фоновые процессы; найти нужные ключи в `man cp` и `man man`, найти справочные страницы по слову *copy*.

**В работе:** ключи подобраны по `man ps`: `ps -ef f`, `ps -N -u root` и другие.
